# เสียงของเกม

วางไฟล์เสียง (`.mp3`, `.ogg` หรือ `.wav`) ในโฟลเดอร์นี้ แล้วอัปขึ้น GitHub — เกมจะใช้ไฟล์แทนเสียงสังเคราะห์ให้เอง
ชื่อไฟล์ต้องตรงตามตาราง (ไม่สนนามสกุล) ถ้าไม่มีไฟล์ เกมใช้เสียงสังเคราะห์ (ยกเว้นเพลงพื้นหลัง ถ้าไม่มีไฟล์จะเงียบ)
ใช้เฉพาะไฟล์ที่ใช้ได้ฟรีและไม่ติดลิขสิทธิ์ (เช่น CC0)

| ชื่อไฟล์ | ใช้ตอน |
|---|---|
| `bgm-lobby` | เพลงห้องรอ (วนซ้ำ) |
| `bgm-auction` | เพลงช่วงประมูล (วนซ้ำ) |
| `bgm-race` | เพลงช่วงเลือกรถ/แข่ง (วนซ้ำ) |
| `bgm-podium` | เพลงหน้าจบเกม (วนซ้ำ) |
| `engine` | เสียงเครื่องยนต์ระหว่างแข่ง (วนซ้ำ) |
| `nitro` | จุด Nitro ของรถตัวเอง |
| `nitroFar` | คนอื่นจุด Nitro |
| `turn` | ถึงตาคุณ |
| `bid` / `chip` / `pass` | กด Bid / ชิปตกกอง / Pass |
| `gavel` / `sold` | ค้อนประมูล / ขายแล้ว |
| `flip` | พลิกการ์ด |
| `pick` | เลือกรถได้แล้ว |
| `beep` / `go` / `rev` | นับ 3-2-1 / ไฟเขียว / เบิ้ลเครื่อง |
| `finish` / `slowmo` / `camera` | เข้าเส้นชัย / เล่นช้า / photo finish |
| `fanfare` / `cheer` | ประกาศที่ 1 / เสียงเชียร์ |
| `coin` / `refund` | เหรียญ / ได้เงินคืน |
| `tick` / `warn` | ติ๊กวินาทีสุดท้าย / เตือนเวลา |
| `campaign-reverse` … `campaign-underdog` | ป้ายเหตุการณ์ Grand Campaign (reverse, double, rain, frenzy, ban, wta, fog, lucky, underdog) |
