# การ์ดรถ — บิดไปสมาชิก (Bid Now, Race Later)

การ์ดรถทุกคันประกอบบนหน้าเว็บจาก 3 ชั้น ได้แก่ ภาพรถ (`art/<id>.webp`) → กรอบ (`frame.png`) → ข้อมูลจาก `data.csv` ซึ่งวางตามตำแหน่งที่กำหนดใน `template.json`
ถ้าต้องการแก้ชื่อหรือ Power ของรถ ให้แก้ที่ CSV ไม่ต้องแก้ภาพหรือโค้ด

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `template.json` | กำหนดตำแหน่ง ฟอนต์ และสีของทุกช่อง โค้ดอ่านค่าจากไฟล์นี้ (ห้ามเขียนพิกัดลงในโค้ด) |
| `frame.png` | กรอบการ์ด 1200×1800 (2 เท่าของต้นแบบ 600×900) ช่องภาพโปร่งใส และไม่มีตัวหนังสือ |
| `back.png` | ด้านหลังการ์ด 1200×1800 ใช้ตอนการ์ดคว่ำอยู่ที่ลานแข่งก่อนเปิดผล |
| `data.csv` | รถ 50 คัน `car-01` … `car-50` (Power 1–50) พร้อมใช้งาน |
| `car-concepts.csv` | แนวคิดภาษาไทยและ `subject` ภาษาอังกฤษของแต่ละคัน สำหรับใส่ใน prompt สร้างภาพ (ไม่ต้องอัปโหลดขึ้นเกม) |
| `preview.png` | ภาพตัวอย่างการ์ดที่ประกอบแล้ว ทั้งแบบเต็มใบและบนกระดาน (กว้าง 88px) |
| `source/frame.svg`, `source/back.svg` | ต้นฉบับแบบเวกเตอร์ ใช้แก้แบบแล้ว render เป็น PNG ใหม่ |

## คอลัมน์ใน `data.csv`

| คอลัมน์ | ชนิด | ช่วงค่า | บังคับ | หน้าที่ | ช่องบนการ์ด |
|---|---|---|---|---|---|
| `id` | ข้อความ | `^[a-z0-9][a-z0-9-]{0,39}$` และห้ามซ้ำ | ✅ | ระบบใช้ และใช้เป็นชื่อไฟล์ภาพ | — |
| `name` | ข้อความ (ภาษาไทยได้) | 1–24 ตัวอักษร | ✅ (ถ้าว่าง ระบบใช้ `Car <power>`) | แสดงอย่างเดียว | แถบส้มด้านบน |
| `power` | จำนวนเต็ม | 1–50 และห้ามซ้ำ ต้องมีครบทั้ง 50 ค่า | ✅ | **ใช้ในกติกา** | ตัวเลขกลางเกจ + เกจ + ไฟ LED |

ภาพรถ `art/<id>.webp` (544×456) แสดงในกรอบภาพ ถ้าไม่มีไฟล์หรือไฟล์เสีย ระบบจะแสดงพื้นสีเทาเข้มพร้อมชื่อรถแทน

ช่องที่ระบบคำนวณจาก `power` เอง (ไม่ต้องกรอก):
- **ไฟ LED 10 ดวง** จำนวนดวงที่ติด = ปัดเศษลงของ power ÷ 5 เช่น 42 → 8 ดวง สี: ดวงที่ 1–4 เขียว · 5–7 เหลือง · 8–10 แดง
- **เกจ** ขีดสีส้มติดตามสัดส่วน power ÷ 50

### กฎของ id
- ใช้ได้เฉพาะตัวพิมพ์เล็ก ตัวเลข และ `-` ยาวไม่เกิน 40 ตัว เช่น `car-01` หรือ `thunderbolt-gtr`
- ห้ามซ้ำ และห้ามเปลี่ยนหลังเปิดให้เล่นแล้ว
- ชื่อไฟล์ภาพต้องตรงกับ id ทุกตัวอักษร: `car-01` → `art/car-01.webp` (ห้ามใช้ `Car-01.webp` เพราะบน Render จะหาไม่เจอ)

## ทำ Google Sheet
1. แถวแรกพิมพ์หัวคอลัมน์ `id`, `name`, `power` ตามนี้ทุกตัวอักษร แล้วล็อกแถวหัว (View → Freeze → 1 row)
2. คอลัมน์ `power` ตั้ง Data validation เป็นตัวเลข 1–50 พิมพ์ตัวเลขเปล่า ๆ ไม่ต้องมีจุลภาคหรือหน่วย
3. กรอกรถ 1 คันต่อ 1 แถว ให้ครบ 50 แถว และไม่มี Power ซ้ำ
4. Export ด้วย File → Download → Comma-separated values (.csv) แล้วเปลี่ยนชื่อไฟล์เป็น `data.csv`

## สเปกภาพรถ
- ไฟล์ `art/<id>.webp` สัดส่วน 544:456 (≈ 1.19:1) คลาดได้ไม่เกิน ±2% ขนาดแนะนำ **1088×912**
- ขนาดไฟล์ไม่เกินประมาณ 300KB
- ให้ตัวรถอยู่ใน 80% ตรงกลางภาพ เพราะระบบอาจตัดขอบภาพออกเล็กน้อย
- ห้ามมีตัวหนังสือ โลโก้ หรือกรอบในภาพ และห้ามใช้ยี่ห้อหรือโลโก้รถจริง
- ภาพจาก AI มักออกมาเป็น PNG หรือสัดส่วนอื่น ให้ครอปเป็น 1088×912 แล้วแปลงเป็น WebP (เช่นที่ squoosh.app ตั้งคุณภาพประมาณ 75)

### Prompt กลาง
```
Stylized racing car illustration, {subject}, three-quarter side view, dynamic motion,
dark asphalt track at night, orange and amber rim lighting, subtle motion blur in background,
bold clean shapes, game card art, 1088x912 landscape (aspect 1.19:1),
no text, no logo, no brand badges, no border, subject centered
```
ให้แทน `{subject}` ด้วยลักษณะของรถคันนั้น เช่น `a low red sports coupe with big rear wing`

## บนกระดาน
- การ์ดบนกระดานกว้างอย่างน้อย 88px และมี **ป้ายชื่อรถ + Power เป็นตัวหนังสือ 11px ใต้การ์ด** เพราะชื่อบนการ์ดขนาดนั้นเล็กเกินอ่าน (Q34)

## อัปโหลด
1. อัปโหลดตอนที่ไม่มีคนเล่นอยู่ เพราะ Render จะ deploy ใหม่และห้องที่เล่นค้างอยู่จะหายหมด
2. อัปผ่านหน้าเว็บ GitHub ได้ครั้งละไม่เกิน 100 ไฟล์ (ภาพ 50 ไฟล์ให้อัปรอบเดียว)
3. หลัง deploy เสร็จ ให้เปิด `/preview` บนมือถือจริง แล้วตรวจว่าไม่มีช่องที่ล้น (ช่องที่ล้นจะมีกรอบแดง) และไม่มีภาพที่หายไป

## ส่วนเสริมของ `card.js` ที่ template นี้ใช้
- `pips.round: "floor"` คำนวณจำนวนไฟที่ติดด้วย `Math.floor` (ค่าเริ่มต้นของ `card.js` คือ `Math.round`)
- `gauge.dash` กำหนด stroke-dasharray ให้ขีดของเกจตรงกับรางขีดในกรอบ
ทั้งสองส่วนเป็นการแก้ `card.js` อ้างอิงเพียงบรรทัดเดียวต่อส่วน และต้องใส่ตอนเขียนโค้ด
