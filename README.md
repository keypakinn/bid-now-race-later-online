# บิดไปสมาชิก (Bid Now, Race Later)

เกมออนไลน์สำหรับผู้เล่น 2–7 คน เล่นบนเบราว์เซอร์มือถือ แบ่งเป็น 2 ช่วง
1. **ประมูล:** ใช้ Coins ที่มีจำกัดประมูลรถแข่ง
2. **แข่ง:** นำรถที่ได้มาแข่งทีละคันเพื่อเก็บ Prize

ใครเก็บ Prize รวมได้มากที่สุดเป็นผู้ชนะ กติกาฉบับเต็มอยู่ใน Game Specification v2

## วิธีเล่น

จำนวนรอบ = จำนวนรอบประมูล = จำนวนรถที่แต่ละคนได้ = จำนวน Race
- ค่าเริ่มต้น = จำนวนผู้เล่น เจ้าของห้องปรับได้ในห้องรอ ตั้งแต่ 2 รอบ จนถึงจำนวนรถ ÷ จำนวนผู้เล่น (เช่น 2 คนได้ถึง 25 รอบ)
- ถ้าตั้งไว้เกินแล้วมีคนเข้าเพิ่มจนรถไม่พอ ระบบลดจำนวนรอบลงเหลือสูงสุดที่ทำได้
- ผู้เปิดประมูลวนตามที่นั่ง (รอบที่ k = ที่นั่ง ((k − 1) mod จำนวนผู้เล่น) + 1)

**ช่วงที่ 1 — ประมูล x รอบ** (พื้นหลังโทนน้ำเงิน)
- เริ่มช่วงมีป้าย PHASE 1 และทุกรอบมีป้าย AUCTION k / x แสดงป้ายละ 2 วินาที เวลาคิดของแต่ละตาเริ่มนับหลังป้ายจบ
- เงินเริ่มต้นตามจำนวนผู้เล่น (เมื่อจำนวนรอบ = จำนวนผู้เล่น): 2 คน = 8 · 3 คน = 10 · 4 คน = 13 · 5 คน = 15 · 6 คน = 18 · 7 คน = 20 Coins ถ้าเปลี่ยนจำนวนรอบ เงินปรับตามสัดส่วน = ค่าในตาราง × จำนวนรอบ ÷ จำนวนผู้เล่น (ปัดขึ้น)
- แต่ละรอบสลับคนเปิดประมูล คนเปิดถูกลง bid 1 Coin ให้อัตโนมัติ (ถ้าไม่มีเงินเลย จะเปิดที่ 0)
- ผลัดกัน bid ตามลำดับ เพิ่มทีละอย่างน้อย 1 หรือ pass คิดตาละ 60 วินาที (กด Bid/Pass แล้วไปคนถัดไปทันที) ถ้าหมดเวลาถือว่า pass · เหลือ 10 วินาทีจะมีตัวเลขนับถอยหลังใหญ่กลางจอของคนที่ถึงตา คนที่ pass แล้วกลับเข้ารอบนั้นไม่ได้
- ช่อง bid ตั้งเป็นขั้นต่ำทุกครั้งที่ถึงตา และหน้าจอแสดงประวัติ bid ทั้งรอบ (ล่าสุดอยู่บน)
- ถ้าเงินไม่พอจะ bid สูงกว่าราคาปัจจุบัน จะออกจากรอบนั้นอัตโนมัติ
- คนที่เหลือคนสุดท้ายเป็นผู้ชนะ จ่ายตามราคาที่ bid และได้รถ Power สูงสุดของชุด
- รถที่เหลือแจกให้คนถัดไปตามลำดับที่นั่ง เรียงจากรถแรงไปอ่อน คนแพ้ไม่ต้องจ่าย
- ผลประมูลแสดง 5 วินาที และเปิดดูย้อนหลังได้ทุกรอบจากกล่อง "ผลการแข่งและการประมูลที่ผ่านมา"
- Coins ที่เหลือหลังจบช่วงประมูลไม่นับเป็นคะแนน

**ช่วงที่ 2 — แข่ง x Race** (พื้นหลังโทนแดงอิฐ)
- เริ่มช่วงมีป้าย PHASE 2 และทุก Race มีป้าย RACE k / x ป้ายละ 2 วินาที เวลาเลือกรถเริ่มนับหลังป้ายจบ
- ทุก Race จะสุ่ม Prize x ค่า และเปิดให้ทุกคนเห็นก่อน
- ทุกคนแตะการ์ดเพื่อเลือกรถ 1 คันแบบลับ (คันที่เลือกมีกรอบเขียว) แล้วกดยืนยัน ภายใน 60 วินาที ทุกคนยืนยันครบ = แข่งทันที · เหลือ 13 วินาทีมีป๊อปอัปเตือนคนที่ยังไม่เลือก/ยังไม่ยืนยัน และเหลือ 10 วินาทีมีตัวเลขนับถอยหลังกลางจอ (ป๊อปอัปไม่บังการกด)
- หน้า RACE START: นับ 3-2-1 แล้วรถทุกคันวิ่งพร้อมกัน Power สูงถึงเส้นชัยก่อน คันที่ถึงเส้นชัยย้ายขึ้นไปตามอันดับ (รวม 10 วินาที)
- จากนั้นแสดงแท่นรับรางวัล 8 วินาที: อันดับ 1–3 มงกุฎทอง/เงิน/ทองแดง อันดับ 4–7 อยู่ด้านล่าง
- Power สูงกว่าได้อันดับดีกว่า และได้ Prize มากกว่า รถที่ใช้แล้วใช้ซ้ำไม่ได้ ดูรถที่เหลือของทุกคนได้ในกล่อง "รถที่เหลือของผู้เล่นแต่ละคน"
- Race สุดท้ายทุกคนเหลือรถคันเดียว ระบบเลือกให้อัตโนมัติ
- ถ้า Prize รวมเท่ากัน ดูจำนวนครั้งที่ได้อันดับ 1 ถ้ายังเท่ากันอีกถือว่าชนะร่วม

**หลุด ออก และผู้ชม**
- ถ้าเน็ตหลุด รีโหลดหน้าเว็บจะกลับเข้าที่นั่งเดิมได้ทุกเมื่อ
- ถ้ากดออกจากเกม ระบบจะเล่นแทนจนจบ (ถึงตาประมูลเมื่อไหร่ pass ทันที ส่วน Race สุ่มรถให้) คะแนนยังนับและยังชนะได้
- รหัสห้องเป็นตัวเลข 4 หลัก (1000–9999)
- จบเกมแล้วกด "กลับสู่ Lobby" เพื่อกลับห้องรอเดิม คนแรกที่กดพาห้องกลับห้องรอ คนที่ยังไม่กดยังดูหน้าผลต่อได้ ผู้เล่นที่ออกระหว่างเกมถูกเอาออกจากห้อง และผู้ชมกดเข้าร่วมเป็นผู้เล่นได้ถ้าห้องยังไม่เต็ม
- หน้าแรกมีปุ่ม "เข้าร่วม" ปุ่มเดียว ถ้าเกมในห้องเริ่มแล้วหรือห้องเต็ม จะเข้าเป็นผู้ชมให้อัตโนมัติ
- ผู้ชมเข้าดูได้สูงสุด 20 คน และจะเห็นเฉพาะข้อมูลที่ผู้เล่นทุกคนเห็นอยู่แล้ว

## ปรับเวลาในเกมเอง

ตัวเลขเวลาทั้งหมดอยู่บนสุดของไฟล์ `shared/config.js` (กลุ่ม `TIME`) แต่ละบรรทัดมีคำอธิบายภาษาไทย แก้ตัวเลขแล้วอัปโหลดไฟล์นี้ขึ้น GitHub ไฟล์เดียว Render จะ deploy ใหม่เอง
- ใส่ได้เฉพาะจำนวนเต็ม 1–600 วินาที ถ้าใส่ผิด ระบบใช้ค่าเริ่มต้นและเขียนเตือนใน log
- `npm test` ใช้ค่าจากไฟล์นี้ แก้ตัวเลขแล้ว test ยังผ่าน

## รันในเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```
npm install
npm start          # เปิด http://localhost:3000
npm test           # ทดสอบกติกา (test/sim.js)
```

หน้า `http://localhost:3000/preview` แสดงการ์ดรถทุกคัน พร้อมบอกจำนวนช่องที่ข้อความล้นและภาพที่หายไป

## Deploy (GitHub + Render แพ็กเกจฟรี)

1. สร้าง repo ใหม่บน GitHub แล้วกด "uploading an existing file"
2. ลาก **ของที่อยู่ข้างใน** โฟลเดอร์นี้ไปวาง ห้ามลากตัวโฟลเดอร์ และห้ามลาก `node_modules`
3. Render → New → Web Service → เลือก repo แล้วตั้งค่าดังนี้

| ช่อง | ค่า |
|---|---|
| Region | Singapore |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | Free |
| Health Check Path | `/healthz` |

4. **อัปเดตเกมหรือการ์ดตอนไม่มีคนเล่นเท่านั้น** เพราะเมื่อ deploy ใหม่ ห้องที่กำลังเล่นจะหายหมด

| Environment variable | ใช้ทำอะไร |
|---|---|
| `PORT` | Render ตั้งให้เอง (ในเครื่องใช้ 3000) |

ข้อจำกัดของแพ็กเกจฟรี:
- ถ้าไม่มีใครเข้าประมาณ 15 นาที เซิร์ฟเวอร์จะหลับ ตอนเปิดครั้งแรกต้องรอให้ตื่นประมาณ 1 นาที
- state ของเกมเก็บในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ท ทุกห้องจะหาย

## การ์ดรถ (`cards/`)

ไฟล์ข้อมูลรถอยู่ใน `cards/` ทั้งหมด ถ้าจะแก้รถ ไม่ต้องแก้โค้ด ดูรายละเอียดใน `cards/README.md`

| ไฟล์ | หน้าที่ |
|---|---|
| `cards/data.csv` | รถ 50 คัน (`id,name,power`) Power ต้องเป็น 1–50 ห้ามซ้ำ |
| `cards/art/<id>.webp` | ภาพรถ 1088×912 เช่น `cards/art/car-01.webp` |
| `cards/template.json` | ตำแหน่งชื่อ, ไฟ LED, เกจ และตัวเลขบนการ์ด |
| `cards/frame.png`, `cards/back.png` | กรอบการ์ด และด้านหลังการ์ด |

- ถ้าภาพรถหาย จะแสดงพื้นสีกับชื่อรถแทน
- ถ้า `data.csv` ผิดหรือหาย เซิร์ฟเวอร์จะข้ามแถวที่ผิดและเติมรถ "Car N" ให้ครบ 50 คัน เกมยังเล่นได้
- รายการแถวที่ผิดดูได้ใน log ของ Render
- อัปโหลดภาพผ่านหน้าเว็บ GitHub ได้ครั้งละไม่เกิน 100 ไฟล์ แล้วเปิด `/preview` บนมือถือเพื่อตรวจ

## โครงไฟล์สำหรับนักพัฒนา

```
server.js              Express + Socket.IO, ห้อง, /api/cards, /preview, /healthz, งานเบื้องหลัง
game.js                class Room — กติกาทั้งหมด (อ้างรหัส R-x-y ของ spec)
server/cards.js        อ่าน/ตรวจ data.csv, เติมรถ default, เลขเวอร์ชันไฟล์การ์ด
shared/config.js       ค่าคงที่ทั้งหมด (spec หัวข้อ 3)
shared/card-schema.js  schema ของ data.csv (spec หัวข้อ 4.1)
public/                index.html, style.css, app.js, card.js (ตัวประกอบการ์ด), preview.html
test/sim.js            test ตาม test scenario T-xx ของ spec
cards/                 ไฟล์การ์ด
```

- **Socket events:** `create`, `join`, `resume`, `spectate`, `leave`, `action {type}`
- **type ของ action:** `game:start`, `auction:raise`, `auction:pass`, `race:select`, `race:confirm`
- **server ส่ง:** `state` แยกส่งให้แต่ละคนตามสิทธิ์ และ event สาธารณะ `auction:result`, `race:prizes`, `race:picked`, `race:result`, `game:over`, `game:cancelled`
- **log ของเกม:** event log ทุก action และบรรทัด `telemetry:game {...}` เมื่อจบเกม ใช้ดูข้อมูลประกอบ playtest
